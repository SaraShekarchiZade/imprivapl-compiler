# ImprivaPL Compiler

## Overview

This project is an implementation exercise for the Compiler Design course. It focuses on defining the grammar of ImprivaPL, a simple imperative programming language, and working with its language-processing components.

## Language Features

According to the language specification, ImprivaPL supports:

- Variable declarations and assignments
- Integer and string values
- Function definitions and function calls
- Output statements using `print`
- Control structures such as `if`, `repeat`, and `for`
- Arithmetic expressions and comparison operators
- Built-in function definitions in the language specification

## Technologies

- Java
- ANTLR4
- Grammar specification (`.g4`)

## Project Structure

- `src/code.g4` — Grammar definition
- `src/Main.java` — Java entry point
- `src/input` — Input file used by the project
- `gen/` — Generated source files, if applicable
- `out/` — Local build output

## Getting Started

1. Clone or download this repository.
2. Open the project in a compatible Java IDE.
3. Make sure the required Java and ANTLR4 dependencies are configured.
4. Review the grammar and input files before running the program.

The exact build and execution steps depend on the project's ANTLR4 configuration and generated source files.
